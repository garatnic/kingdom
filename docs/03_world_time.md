# 03 世界・地形・時間仕様書 — 詳細版 v0.2
> **確定方針**：原始集落開始、探索による世界拡張、近景詳細/遠景簡略、標準速度、終了中の進行なし。以下の具体値・アルゴリズムはすべて**暫定**。

## 1. 時間の単位と速度【暫定・推奨】
ゲーム内時間の正規表現は `worldTimeTick`（開始時0、整数、1 tick=ゲーム内0.1分）。1日=24ゲーム時間=1,440ゲーム分。1年=30ゲーム日=43,200ゲーム分。1年は5季節ではなく4季節（各7/8日、割当は春8・夏7・秋8・冬7）。初期版は季節の表示のみ、気象影響は後続。
- **通常速度**：現実1秒=ゲーム内12分。現実2分=ゲーム内1日、現実60分=ゲーム内1年。
- **速度切替**：停止0、通常1、5倍、20倍。倍率は世界時間の進行に適用し、AI更新間隔の実時間固定にはしない。
- 住民寿命の目安を人間20〜40ゲーム年とすると、通常速度で世代交代は20〜40実時間時間程度。初版の30分テストでは世代交代を十分観察できないため、**長期シミュレーションテスト/倍速で確認**する。30分内の出生や建国を保証しない。
- UIには「第N年 春 第D日 HH:MM」を表示。年は1始まり。暦変換は純関数で実装。
- **以前の6日=1年案は未採用**。これを他資料の基準にしない。

## 2. シミュレーション刻み【暫定】
固定刻み `SIM_STEP_REAL_MS=100`、通常速度で1刻み=ゲーム内1.2分=12 worldTimeTick。ゲーム内1分=10 tick、1時間=600 tick、1日=14,400 tick、1年=432,000 tick。内部時間は整数 `worldTimeTick` のみ保存し、表示時に分へ変換する。速度5倍/20倍では1刻みにつき60/240 tickを進める。
- 描画：`requestAnimationFrame`。フレーム時刻差は最大250msまで受け入れ、1フレームで最大5刻みを処理。超過分は破棄してスローダウンを許容し、無限追いつき処理を禁止。
- 移動/戦闘：固定刻みで更新。AI意思決定：ゲーム内約30分ごと、人物IDで分散。国策：ゲーム内1日ごと。経済生産・人口判定：ゲーム内1時間または1日ごと。
- 非表示時は `visibilitychange` で停止し、復帰時は実時間差をシミュレーションへ加算しない。保存中の処理は安全に完了させる。閉じている間の進行なし。
- `gameSpeed` は一時停止/倍速操作でのみ変更。セーブには速度・世界時刻・シミュレーション残余時間を保存する。

## 3. マップ【暫定】
現在は256×256タイルの固定世界、1タイル32論理px、座標原点は左上。タイル座標整数 `x,y`。表示位置は小数可。地形：grass, forest, mountain, water。地形レイヤーと資源ノード・建物・ユニット・道路・占有レイヤーを分離。
- `terrain[x,y]` は1タイル1種。草原通行コスト1、森林1.5、山3、水は通行不可。建築占有中のマスは通行不可（入り口例外は建物定義）。
- 初期集落中心の周囲に、到達可能な食料・木材・石材が最低1箇所あることを生成後に検証。不適合時はシードを変えずに確定的な補正を適用し履歴へ記録。
- 地形生成：シード付きPRNG + 連続ノイズ/近傍平滑化。全てのゲームプレイ乱数はシード由来の状態を保存する。

## 4. 経路探索【暫定】
4近傍A*、ヒューリスティックはマンハッタン距離。コストは地形+危険補正。進入禁止地形を通らない。対象が占有される場合は周囲の到達可能な作業地点をゴールとする。
- 再探索：目的地が変わったとき、障害物更新、移動停滞5ゲーム分、経路失敗時。
- 連続3回失敗した行動は60ゲーム分クールダウン。AIは別の目標へ切替。
- 経路キャッシュは地形/建築変更の `navigationVersion` で失効させる。

## 5. チャンク拡張【将来・確定方針】
32×32タイル/チャンクを推奨。未探索チャンクはシードから生成。地形変更は差分保存。生成済み・探索済み・可視は別状態。遠景集約の人物・家族・国家IDを失わない。Ver.0.1は単一固定マップで、無限拡張は実装対象外。

## 6. 受入テスト

T03-02：停止中はworldTime不変。5倍で通常の5倍進む。
T03-03：非表示30秒後の復帰で時間ジャンプしない。
T03-04：同一シードで初期地形と初期資源が一致。
T03-05：水・占有建物を通過せず、到達不能時に別行動へ移る。
T03-06：1年=30日、4季節の日数合計=30日。

## 7. 未決定
寿命/妊娠/成人の実際の年数、季節のゲーム効果、倍速時の負荷制御、長期世代交代の演出。時間比率は初回実装時に体感検証してから確定する。

## v0.6 時間単位の統一【暫定】
すべての日時・出生・攻撃クールダウン・建築作業期限・研究更新は `worldTimeTick`（1 tick=ゲーム内0.1分）へ正規化。旧文書中の `worldMinute`、`birthWorldMinute`、`worldTimeMs` は非推奨の旧表記。定数は docs/14 に集約。保存時は整数tick以外の時刻を正本にしない。

### Ver.0.2の探索実装【暫定】

冒険者は開始2日経過後、到達可能な東端・南端を調査する。到達すると32タイル厚の領域が開き、道と食料・木材・石材の採集地が追加される。生成はシードと座標に基づき、境界に接続する道だけは到達地点に合わせる。既存タイルの座標と保存形式を維持するため、初期実装は東・南への拡張と各辺128タイルを上限とする。
