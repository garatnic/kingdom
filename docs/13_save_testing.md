# 13 保存・性能・テスト
## 保存【確定方針】
ゲーム終了中の進行なし。IndexedDBで自動保存、手動保存、外部エクスポートに対応する設計案【保存方式は暫定】。
## 保存案
60秒ごと、最新3世代、JSONエクスポート。保存形式にschemaVersionを持たせ、復元時に整合性チェック。保存完了前に既存の正常データを消さない。
## 性能目標【暫定】
PCで60fps描画目標。Ver.0.1は詳細住民100人程度、将来は数百人。FPS・更新時間・メモリ・セーブサイズを計測し、実測で調整。
## テスト
1. 30分連続実行：停止・NaN・無限ループなし。
2. 資源保存則：採集・運搬・建築で重複増減なし。
3. AI：到達不能・満杯・対象消滅時に再計画。
4. 人物：出生・死亡・親子IDの整合。
5. 国家：建国・所属変更・滅亡後も参照可能。
6. 戦闘：HP・撤退・死亡・報酬の整合。
7. セーブ：保存→再開後に時間・資源・国家・家系が一致。
8. タブ非表示：進行停止。再開時に巨大な経過時間を一括適用しない。
## 未決定
対応ブラウザ最低バージョン、セーブ容量上限、モバイル性能基準。
