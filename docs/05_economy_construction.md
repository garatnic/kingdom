# 05 資源・経済・建築
## Ver.0.1資源【暫定】
食料、木材、石材、鉄、魔石。採集可能量、再生速度、運搬容量、倉庫在庫を区別。
## 基本循環
採集→持ち運び→倉庫に納品→建築/生産に消費→住宅・食料供給→人口・労働力増加。
## 職業【暫定】
農民、木こり、鉱夫、建築家、冒険者。鍛冶等の専門職は後続追加または暫定的に建築/生産役が兼務。
## 建物【暫定】
住宅、畑、倉庫、鍛冶屋、ギルド、兵舎。各建物は建築コスト、進捗、占有面積、容量、耐久、稼働条件を持つ。
## 整合性ルール
資源は採集確定時にノードから減少、納品時に倉庫へ加算。建築用資材は着工時または搬入時に予約し二重消費を防ぐ。未完成建物は機能しない。倉庫満杯や運搬者不足時の待機と再計画を実装。
## 将来
交易価格、物流網、道路の自然発生、魔法産業、資源枯渇と森林再生、都市間交易。
