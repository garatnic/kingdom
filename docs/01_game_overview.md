# 01 ゲーム企画・基本仕様
## コンセプト【確定】
神として眺める自律型ファンタジー文明シミュレーション。住民の生活、冒険、研究、国家の興亡、世代交代が相互作用し、歴史を生成する。明確な勝利条件なし。
## 確定方針
- 2D細密ドット絵。素材はプログラム生成。詳細情報パネル。
- 複数国家が自動誕生。多種族共存。本格ファンタジー。
- 原始的集落から開始し、文明時代が進化。国家ごとに発展速度が違う。
- 魔法は研究により発展。人物・家系・国家の歴史を記録。
- 近景は個別AI、遠景は簡略計算。探索で256×256固定世界の資源や出来事を発見する。
- 自動イベント追跡カメラ。神の干渉は無制限。
- 日常と大事件の頻度はバランス型。作業と戦闘を細かく描写。
- ゲームを閉じたら進行しない。
## 体験の核
採集→生産→建築→人口増加、冒険→討伐→報酬→成長、研究→産業変化→外交・戦争、出生→継承→歴史、という因果が視覚的に確認できること。
## 対象環境【暫定】
PCブラウザ中心、スマホにも対応。HTML/CSS/JavaScript。
