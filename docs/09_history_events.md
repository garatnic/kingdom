# 09 歴史・イベント
## 記録対象【確定】
人物の出生・死亡・婚姻・職業・功績、親子関係、国家の建国・君主・戦争・滅亡、研究発見、重要建築。
## イベント形式【暫定】
id, worldTime, type, actorIds[], nationIds[], location, importance, payload, causeEventIds[]。ID参照を使い、改名・死亡後もリンクを維持。
## 頻度
日常は常時、中規模は状況次第、大事件は希少。事件を単純な固定タイマーで捏造せず、実際の原因（魔物増殖、外交悪化、研究達成）から発生させる。
## 閲覧
世界年表、人物伝、家系図、国家史、イベント検索。自動カメラは重要度と位置・お気に入りをもとに注目イベントを選ぶ。
## データ保持
移動や食事の逐次ログは短期で破棄。出生死亡・親子・国家・重大事件は長期保持。長期保存量の上限と集約方式は未決定。
