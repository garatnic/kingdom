# 09 歴史・イベント仕様 — 詳細版 v0.5
> **確定**：人物伝・家系・国家史を記録し、出来事は世界の実際の状態から生まれる。以下の構造・閾値は**暫定**。

## イベントの唯一の発生経路
各システムは事実を確定するトランザクションを実行し、その成功時にイベントを発行する。歴史側が出生・建国・討伐・研究を自発的に生成しない。イベント発行は `emitOnce(sourceTransactionId,type)` で重複防止。失敗/ロールバックした処理は歴史へ記録しない。

## スキーマ
```js
{
 id:"event:102", sourceTransactionId:"tx:204",
 worldTimeTick:123456, type:"monster_defeated",
 importance:2, actorIds:["citizen:8"], nationIds:["nation:1"],
 settlementIds:["settlement:1"], targetIds:["monster:9"],
 location:{x:35,y:19}, causeEventIds:["event:88"],
 payload:{monsterSpecies:"goblin"}, summaryKey:"history.monster_defeated"
}
```
`worldTimeTick` は03の整数時間軸に一致。名前・国名は参照IDから表示し、死亡・滅亡後も履歴データで解決する。削除済み対象はイベントに最低限の表示用スナップショットを保持。payloadはJSON互換の型付きデータに限定。

## 重要度と保持【暫定】
| レベル | 例 | 保存 |
|---|---|---|
| 0 | 移動・攻撃・食事 | 長期保存しない。デバッグ時のみリングバッファ |
| 1 | 依頼受諾、日常作業完了 | 直近500件 |
| 2 | 魔物討伐、建築完成 | 直近2,000件。主要人物に関わるものは昇格可 |
| 3 | 婚姻、集落開拓、指導者交代 | 永続 |
| 4 | 研究発見、英雄的勝利、建国 | 永続 |
| 5 | 死亡、文明進化、国家滅亡 | 永続 |
出生はレベル3、親子関係の正本は04の人物データ。戦争の開始・終結は将来レベル4。永続イベントが増えすぎた場合のアーカイブ圧縮は将来課題で、初版では無断削除しない。

## 人物伝・国家史・家系図
人物伝は `actorIds` と `targetIds` の逆引き、国家史は `nationIds` の逆引き、家系図は `parentIds/childIds/partnerId` を正本として生成する。検索用索引は再構築可能な派生データとしセーブ必須にはしない。生存者/死亡者の両方を閲覧可能。

## 自動カメラ候補
イベント重要度4以上を候補にし、重要度×10 + 未視聴ボーナス5 + お気に入り人物ボーナス8 - 同種連続ペナルティ10 で優先度を計算。自動追跡中は現実30秒以上の保持を基本とするが、死亡/国家滅亡の重要度5は割込可能。位置のないイベントは首都・関係人物の位置へフォールバック。候補なしでは現在位置を維持。手動操作中は自動移動しない（11参照）。

## テスト
T09-01 同一tx/typeのイベントが二重記録されない。
T09-02 死亡人物の名前・家系と過去イベントを閲覧できる。
T09-03 重要度0の戦闘フレームログが永続セーブを肥大化させない。
T09-04 研究完了イベントが研究解禁より先に発行されない。
T09-05 索引を削除しても人物伝・国家史を再生成できる。
