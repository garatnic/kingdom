# 世界・国家・都市の拡張仕様（2026-11-21 確定方針）

## 目的
都市が建物の増加に応じて地理的に成長し、離れて誕生した複数国家が長期的に接近・接触する自律観察世界を実現する。今回は既存の生活・経済・外交・戦争・資源再生をできる限り維持し、下記の変更に限定する。

## 確定した変更
1. **世界サイズ**：当面は256×256タイルの固定マップを採用する。探索による無限チャンク拡張は保留し、既存の探索・発見体験は維持する。従来の64×64初期マップおよび暫定128×128拡張を置き換える。固定マップ内の未探索領域の公開方法は実装設計で整合させる。
2. **国家上限**：同時に存在できる国家数の上限を2から**5**に変更する。開始時に5国を配置する意味ではない。自然建国・独立開拓による発生条件は原則維持する。滅亡した国家が枠を占有し続けないようにする。
3. **独立開拓距離**：出発元集落の中心からの開拓候補距離を原則**46〜54タイル**とする（既存の12〜18タイルから変更）。既存集落との最低間隔、資源・通行可能性など、ほかの適地条件は原則維持。探索領域端の例外経路など既存の特殊処理も確認し、この距離方針に矛盾しないよう調整する。遠方優先の探索順は今回確定していないため、実装時に恣意的に追加しない。
4. **建築可能範囲**：集落中心からの固定半径制限をやめ、**同じ集落に所属する既存の建物から6タイル以内**の地点を新築候補とする。建物が増えることで建築可能範囲が連鎖的に拡張する。既存の地形・到達・物流・資材・施設需要等の条件は維持する。
5. **領土**：集落中心から固定6タイルの勢力圏ではなく、**所属する建物の増加に連動して国家の領土が拡張**する。建築範囲と領有判定は別概念として扱い、他国の既存領土を新築だけで自動奪取しない。他国領への住民の進入による国境摩擦・外交・戦争は維持する。

## 実装上の整合条件（新しいゲームルールではない）
- 既存建物の所属集落・国家、完成前建築現場、国家未成立の集落、占領・滅亡後の所有権を一貫して扱う。
- 領土が接触・競合する際の帰属を決定的に判定し、セーブ復元後も変わらないようにする。境界接触だけで自動開戦する新ルールは追加しない。
- 建物を連鎖的に建てられても、道路・到達・資源・建築需要など従来の制約を飛ばさない。
- 5国家に伴う外交関係、戦争相手の選択、複数戦線、履歴、UIの2国家前提を洗い出し修正する。
- 256×256化による地形生成、カメラ、探索、経路探索、遠景集約、保存・復元、描画の性能・整合を確認する。世界全体を毎tick全走査しない設計を優先する。
- 旧セーブは既存の互換方針に沿って扱い、必要な移行規則を明記する。

## 今回は確定・追加しない
人口100人ごとに領土半径を6増やす方式、人口の半数を開拓に出す方式、複数都市を同一国家に所属させる新制度、交易・市場・斥候の新AI、資源再生周期の変更、無制限国家数、無限チャンク拡張。これらは会話で検討した案であり今回の確定変更ではない。

## 開発計画への組み込み
Ver.0.2以降の世界・建築基盤とVer.0.4の多国外交に横断する変更として実装する。先に256×256固定世界と保存・探索の整合、次に建築と領土、次に46〜54タイル開拓と5国家対応を進め、各段階で回帰テストと長期観察を実施する。実装・公開は別作業であり、この文書の追加だけでは機能完成を意味しない。
