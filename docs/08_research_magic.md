# 08 文明・研究・魔法 — 詳細版 v0.4
> **確定**：文明は国家ごとに異なる速度で進化し、魔法は独立研究で発展する。以下の技術ツリー、条件、数値は**暫定**。

## 1. 研究の所有者
国家成立前は集落が `researchState` を保持。建国時に集落の研究を国家へ引継ぎ、集落側は参照先 `researchOwnerId` を更新する。独立開拓隊は母集落の既知技術のうち基礎技術のみ継承（初版では農業基礎と建築基礎）。国家間で研究進捗を共有しない。

## 2. データ形式
```js
technology = {
 id:"farming_1", branch:"farming", era:"primitive",
 prerequisiteIds:[], researchCost:100,
 requires:{population:4,buildings:[],resources:{}},
 effect:{farmYieldMultiplier:1.25}
};
researchState = {
 ownerId:"settlement:1", unlockedIds:[],
 activeTechId:"farming_1", progressById:{farming_1:0},
 knowledgePoints:0, lastUpdateAt:0
};
```
`unlockedIds` は集合として扱い重複を禁止。研究進捗は所有者単位で管理。

## 3. 研究点と進捗【暫定】
ゲーム内1時間ごとに `researchGain = 1 + floor(adultPopulation/6) + scholarBonus + policyBonus` を獲得。初期12人では毎時3点、1日72点。専門研究職はVer.0.1に設けないため、人口・国策・施設効果を代替する。
- `scholarBonus` は魔法適性の高い住民が1人以上なら+1（魔法分野のみ）。`policyBonus` は研究重視政策時+1。
- 同時研究は1件。進捗は研究点から毎時移し、前提未達なら研究選択不可。研究中に前提建物を失っても既得進捗は残るが、完了判定は条件回復まで保留。
- 研究が完了したら進捗を差し引き技術を解禁し、09の `research_unlocked` イベントを発行。進捗のオーバーフローは研究点残高へ戻す。国家AIは研究候補を効果・不足・指導者性格で採点。

## 4. Ver.0.1の4技術【暫定】
| ID | 分野 | 前提 | コスト | 効果 |
|---|---|---|---:|---|
| farming_1 | 農業 | 人口4以上 | 100 | 畑の収穫量×1.25（端数切捨て） |
| building_1 | 建築 | 住宅1棟 | 120 | 建築作業速度×1.20 |
| weapons_1 | 武器 | 鉄2を**倉庫で保有**、鍛冶屋1棟 | 180 | 冒険者の基礎攻撃+2 |
| magic_1 | 魔法 | 魔石1を**倉庫で保有**、魔法適性者1人 | 200 | 適性者に初級魔法を解禁 |
鉄/魔石は研究の前提として存在確認するだけで、明示的な消費をしない。武器/魔法研究に必要な希少資源の入手方法は05/07と接続。初版の研究は上記4件で、時代進化は表示上の条件のみ。

## 5. 魔法【暫定】
`magic_1` 解禁後、magicSkill>=1の住民が初級攻撃魔法を使える。射程3タイル、基礎威力8、詠唱10ゲーム分、再使用30ゲーム分、消費MP10。MP最大30、ゲーム内1時間で5回復。通常攻撃と同じ命中確定イベントを用い、戦闘AIが射程と残MPで選択。
- 魔法研究の成立前は、魔法適性者が存在しても魔法を使用できない。
- 初版の属性は無属性。火/水/風/土/生命/空間などの分岐は将来。
- 魔法工学、召喚、治癒、広域魔法、研究の伝播・衰退は将来。

## 6. 文明時代【暫定】
原始→農耕→鉄器→王国→魔導→神話。**Ver.0.1で実際に判定するのは原始→農耕のみ**。
- 原始→農耕：farming_1解禁、畑2棟稼働、人口8以上を3日継続。
- 以降の時代は将来：鉄器（鍛冶技術と鉄生産）、王国（政治施設・複数集落）、魔導（魔法工学）、神話（高次研究）。条件未確定のため初版で自動遷移させない。
- 国家成立前の集落も文明段階を持ち、建国時に引継ぐ。国家ごとに研究点・選択技術・発展条件が異なり、結果として発展速度が変わる。
- 研究済み技術は人口減少だけで失わない。施設喪失で実用効果が停止する技術は別フラグで管理。

## 7. 国家AIとの接続
研究重視の国策は `policyBonus` に反映し、食料危機では研究より農業・建築を優先。研究AIは研究を直接解禁せず、研究点と前提の確認を経由する。冒険者の武器/魔法能力は研究状態を参照して毎戦闘評価する。

## 8. 受入テスト
T08-01：人口12の集落が通常時毎時3研究点を得る。
T08-02：農業研究後、畑8単位/収穫が10単位になる。
T08-03：武器研究は鍛冶屋と鉄2がないと完了しない。
T08-04：魔法研究前は魔法使用不可、解禁後はMP消費して発動。
T08-05：二国家の研究進捗・技術解禁は独立する。
T08-06：国家成立時に集落の既知技術を消失させない。
T08-07：文明進化は条件3日継続で一度だけ記録。

## v0.6 研究到達性と職業の整合【暫定】
- 研究点は住民の職業と無関係に人口・政策から生じるため、初版の職業5種に研究者職を追加しない。
- 魔法適性者は `traits.magicAffinity>=0.7`。初期12人に最低1人を生成補正で保証し、魔法研究解禁時に当該人物の `skills.magic` を1以上にする。これにより「適性者がいるが魔法を使えない」という矛盾を解消。
- 鉄・魔石は05の到達可能な採掘ノードから供給。鍛冶屋建設に鉄2を消費するため、武器研究の鉄2保有条件を満たすには別途鉄を採掘する。
- 研究の鉄2/魔石1は**倉庫の利用可能在庫**で判定する。建築予約中・輸送中・人物所持分は含めない。

### Ver.0.3の追加時代【暫定】

- 鉄器時代は武器研究、鍛冶屋、利用可能な鉄2、人口8を10日継続。
- 王国時代は正式な国家で、鋼鉄鍛造、ギルド、倉庫、人口16、人口の2倍の食料を12日継続。
- 魔導時代は魔法増幅、ギルド、魔石2、人口16を20日継続。
- 鉄器時代で鋼鉄鍛造（近接威力+2）と灌漑（基礎収穫量の25%分を加算）、王国時代で魔法増幅（呪文威力+4）を研究できる。備蓄条件は利用可能在庫で判定し、研究自体では消費しない。

## 治癒術【暫定】

王国時代以降、魔法研究済み・魔力適性者あり・ギルドあり・使用可能な魔石1個以上で治癒術（850知識点）を研究できる。研究した所属国・集落の適性者は、空腹度80未満で実際に休息中に、HP75未満ならゲーム内1時間に1回、MP10でHP12を自己回復する。

### 神話時代と豊穣魔法【暫定】

魔導時代で灌漑、魔力適性者、ギルド、使用可能な魔石5個を満たすと、3000知識点で豊穣魔法を研究できる。研究した国・集落の畑では収穫倍率に0.5を加算する。魔導時代の国が同研究、20人以上、ギルド1棟、畑3棟、魔石5個以上、使用可能な食料が人口×3以上を30日連続で満たすと神話時代へ進む。
