# 02 開発ロードマップ — Ver.0.1 凍結スコープ
> このページは実装対象の判定基準。ユーザー確定方針はDECISIONS.md、個別数値はdocs/14に従う。数値は**暫定**。

## Ver.0.1で必須
- 64×64、初期12成人・1集落・国家0、3種族、5職業、5資源、6建物、魔物2種、研究4件、国家上限2。
- 自律行動：食事・睡眠・採集・運搬・建築・探索・冒険・戦闘・帰還・婚姻・出生・死亡。
- 国家：集落の建国、独立開拓隊による2国目の成立、政策差、関係値と友好/中立/敵対の表示。**全面戦争・占領は対象外**。
- 研究：農業/建築/武器/魔法の解禁と実効値、文明段階は原始→農耕のみ。
- 観察：世界史、人物伝、家系図、国家史、イベント自動カメラ、詳細インスペクタ。
- 神の介入：生命・資源生成、地形変更、魔物召喚。無制限、ただし配置安全性・世界上限の検証は必要。
- IndexedDB 3世代保存、JSON入出力、閉じている間の進行なし。
- Canvas2Dのプログラム生成ドット絵、歩行・採集・建築・戦闘・詠唱の視覚反映。

## 明確にVer.0.1対象外
無限チャンク拡張、近景/遠景集約の実装、6種族への拡張、全面戦争、占領、魔物生態系、時代「鉄器」以降、異種族婚姻、災害・祝福・操作取り消し、オンライン同期。将来構想は維持。

## 開発順序と段階完了ゲート
1. **基盤**：時間、PRNG、ID、地形、移動、描画。ゲート：固定シード再現と停止/再開。
2. **生活**：欲求、採集、物流、建築、食料、婚姻/出生/死亡。ゲート：倉庫/資源保存則、食料収支のテスト。
3. **冒険**：魔物、依頼、戦闘、撤退、戦利品。ゲート：討伐→回収→帰還の通しテスト。
4. **国家/研究**：建国、独立開拓、国家政策、研究/魔法。ゲート：シード指定で2国成立、4研究到達可能。
5. **観察/保存/神**：歴史、カメラ、インスペクタ、介入、セーブ。ゲート：保存復元・介入重複排除。
6. **統合検証**：通常速度30実分の安定性、20倍の長期進行、再現性、リソース整合。

## Ver.0.1 完了判定
全必須機能に実行可能な受入テストがあり、失敗0。最小シード3種類（標準、食料不足、障害地形）で検証。長期統合では少なくとも1回、国家成立・研究完了・冒険帰還・死亡・出生を**テスト用に条件を整えて**再現する。自然放置30分で必ず出生/建国することは要求しない。仕様の暫定数値は実測で調整可能だが、調整時はdocs/14と関連文書を同期更新。

## 実装準備と実装完了は別
本書は開発契約であり、実行コード・テストの合格を意味しない。テスト実行前はVer.0.1「仕様ベースライン完成」、実行合格後に「Ver.0.1実装完成」と呼ぶ。
