# 02 開発ロードマップ
## Ver.0.1【暫定スコープ】
64×64タイル、初期12住民、上限目安100詳細住民、3種族（人間・エルフ・ドワーフ）、最大2国家。5職業、6建物、5資源、2魔物、4研究分野。生活・冒険・国家の最小循環を**実動**させる。
## 段階
1. 世界生成・描画・カメラ・移動・時間。
2. 採集・物流・建築・食料・住民の欲求と出生死亡。
3. 魔物・冒険者・戦闘・撤退・帰還。
4. 国家成立・研究・簡易外交・異なる国家方針。
5. 情報パネル・歴史・神の操作・保存・自動カメラ。
## 受入基準
- 放置で資源が採集され建物が完成する。
- 食料・住居・危険が人口変動に影響する。
- 冒険者が出発、戦闘、帰還または死亡する。
- 国家が独立した方針で行動し研究結果が反映される。
- イベントから人物・国家・家系を辿れる。
- セーブ後の復元で資源、人物ID、親子関係、国家が維持される。
- 通常速度30分の連続実行で停止・重複生成・資源の不整合がない。
## 将来
チャンク無限拡張、数百人以上の詳細表示、6種族、6文明時代、全面戦争、魔物生態系、魔導文明、複雑な外交。初版の完成条件に含めない。
