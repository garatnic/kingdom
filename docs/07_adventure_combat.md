# 07 冒険者・魔物・戦闘 — 詳細版 v0.4
> **確定**：冒険者・魔物・戦闘が自律的に発生し、細かなアニメーションと人物史に反映される。以下の数値・判定式はすべて**暫定**。

## 1. Ver.0.1対象
冒険者職、スライム・ゴブリン、探索・索敵・追跡・攻撃・撤退・帰還、戦利品、経験、負傷・死亡、集落の討伐需要。魔物の高度な繁殖・巣・戦争は将来。

## 2. 実体データ
```js
monster = {
 id:"monster:1", species:"slime", x:40.5,y:30.5,
 hp:30,maxHp:30,attack:5,defense:1,speed:0.8,
 sightTiles:5,attackRangeTiles:1,cooldownWorldMin:10,
 lastAttackAt:-999,homeTile:{x:40,y:30},
 state:"wander",targetId:null,spawnRegionId:"region:1",
 loot:{food:1},alive:true
};
adventure = {
 citizenId:"citizen:8",questId:"quest:1",
 state:"prepare",targetMonsterId:null,homeSettlementId:"settlement:1",
 departedAt:null,kills:0,xp:0,retreatUntil:0

```
冒険者も住民IDを持つ同一人物であり、戦闘専用に複製しない。HP、性格、技能、インベントリは04の人物データが正本。モンスターは人物と別ID空間。

## 3. 魔物の発生【暫定】
- 64×64初期マップに最大12体（スライム8、ゴブリン4）。初期は集落中心からマンハッタン距離10以上、通行可能で非占有、画面上の安全地帯を避けて配置。
- 生存数が上限未満ならゲーム内6時間ごとに1体を補充候補とする。ただし出現候補地は集落中心から10タイル以上かつ冒険者・住民から5タイル以上。候補がなければ生成を延期。
- スライム：HP30、攻撃5、防御1、速度0.8タイル/ゲーム10分、索敵5タイル。ゴブリン：HP45、攻撃9、防御3、速度1.1、索敵7。数値は balance に集約。
- 初版の魔物は徘徊、敵発見時追跡、帰巣、死亡。徘徊範囲は出現点から8タイル。集落に近づけば脅威イベントを発生し、防衛需要が増す。

## 4. 冒険依頼と出発【暫定】
集落AIは毎ゲーム日、周辺の魔物・被害・冒険者数を確認。危険が高い場合に `quest:clear_monsters` を最大2件発行。国家成立前でも集落が依頼を発行可能。
- 依頼データ：id,settlementId,kind,targetRegion,targetId,rewardFood,rewardResource,status,claimedBy,createdAt,expiresAt。
- ギルド未建設でも簡易依頼板を利用可能。ギルド完成後は同時依頼数や報酬効率を向上（具体効果は将来）。
- 冒険者AIが `score = rewardValue + bravery*20 + combatSkill*5 - distance*2 - estimatedRisk*20` で依頼選択。食事・睡眠・重傷時は受諾不可。単独依頼は1人だけがclaim。
- 受諾→準備（食料1確保）→移動→索敵→交戦/回避→戦利品回収→帰還→報酬受取。帰還時の報酬は集落倉庫から現物を移動し、足りなければ未払い債務として記録。資源を無から生成しない。

## 5. 戦闘状態機械
`idle -> detect -> evaluate -> approach -> windup -> strike -> cooldown -> evaluate`、離脱時 `retreat -> return`、死亡時 `dead`。
- 敵発見：視線距離（4近傍経路距離またはマンハッタン距離）以内、障害物遮蔽は初版では簡略化。索敵はゲーム内5分ごと。
- 攻撃は射程内、クールダウン終了、HP>0の条件でのみ発生。準備動作完了後のヒット時に1回だけダメージを確定。
- ダメージ `max(1, floor(attack * random(0.9,1.1) - defense*0.5))`。乱数は保存PRNG。命中率は初版100%、回避は後続。
- 冒険者の初期基礎値：HP100、攻撃10、防御3、近接射程1、攻撃間隔10ゲーム分。戦闘技能Lvごとに攻撃+1（上限10）。研究の武器強化は08に定義。
- 退却：HPが最大HPの35%以下、敵推定戦力が自身の1.5倍超、または恐怖度80以上。勇敢さが高いほど退却HP閾値を下げる（最小20%）。退却先は集落または安全地点。
- HP0で死亡。死体から戦利品を地面のドロップに移し、戦闘参加者のIDを履歴へ記録。死亡処理は04の共通処理を使う。

## 6. 戦利品・経験【暫定】
- スライム：食料1を確率50%、魔石1を確率10%。ゴブリン：木材1を確率50%、鉄1を確率20%。それ以外は空。
- 撃破時の経験：スライム5、ゴブリン10。撃破に寄与した冒険者に分配、経験20で戦闘Lv+1（次Lvの必要経験は20×次Lv）。初版のレベル上限10。
- ドロップは地面の現物。回収後に人物所持へ移り、倉庫納品時のみ集落資源に加算。ドロップ生成時に経済台帳の**外部流入**として記録し、移送中の二重生成を防止。

## 7. 国家・研究・歴史との接続
- 国策の `danger` は直近3ゲーム日の襲撃・負傷・魔物接近を0〜1へ正規化。高いほど討伐依頼・兵舎建築需要が増える。
- 武器研究は冒険者の攻撃力に乗算/加算。魔法研究は適性者が初級魔法を使用可能（08参照）。
- 初討伐、強敵撃破、負傷、死亡、依頼達成を09のイベントへ発行。日常的な攻撃1回ごとの履歴は長期保存しない。

## 8. 受入テスト
T07-01：冒険者が依頼を受けて出発、魔物を索敵、交戦、帰還する。
T07-02：HP35%以下で退却を試み、逃走先が到達不能なら再計画する。
T07-03：攻撃1回につきダメージ確定は1回だけ。
T07-04：死亡人物は04の家系に残り、戦闘AIから外れる。
T07-05：戦利品の生成・回収・納品は台帳上1回だけ。
T07-06：同一シードと同一入力で戦闘結果が再現する。
T07-07：冒険者不在/資源不足でも依頼は永久ロックせず期限切れになる。

## v0.6 希少資源・魔法の連携【暫定】
- 鉄と魔石の基礎供給源は05の採掘ノード。討伐ドロップは追加供給であり、研究解禁に必須ではない。
- `magic_1` 完了時、魔法適性者（`traits.magicAffinity>=0.7`）に `skills.magic` を最低1付与する。MPは戦闘時に人物状態へ保持し、セーブ対象とする。

### Ver.0.5の冒険者成長【暫定】

討伐に加えて成功帰還で経験4を得る。成功回数1・5・20で探索者・熟練者・英雄の称号を記録する。戦闘Lv.2で鉄製、Lv.5で鋼鉄装備を選べる。鍛冶屋・対応研究・利用可能な鉄を要し、出発時に装備代として鉄2または3を使用する。鉄製は近接+1・防御+1、鋼鉄は近接+3・防御+2。討伐数・装備を保存し、旧セーブは未装備・討伐実績0から再開できる。

### Ver.0.7の生息地【暫定】

スライムは草原・森林、ゴブリンは森林・山地、ウィスプは森林で繁殖する。6時間ごとに補充候補を探し、同種が半径6タイル内に3体未満なら親の周辺で繁殖できる。親と子の繁殖間隔は1日。絶滅した種は最終死亡から1日経過後に適地へ流入できる。ウィスプの自然流入地点は拡張地域の森林とする。集落10タイル・住民5タイルの範囲は新たな出現地点の対象外。

### 捕食【暫定】

ウィスプは巣の行動圏内で視界に入ったスライムに接近し、日次でマンハッタン距離1のスライム1体に10ダメージを与える。受注済みの討伐対象の捕食・狩りへの参加は除外する。死亡した魔物の未受注依頼は終了し、戦利品を出さず、捕食を世界史に残す。

### 巣【暫定】

魔物は生息拠点からマンハッタン距離4以内におり、拠点が通行可能で適した地形にあるときに繁殖する。同種の拠点が距離6以内に3体分ある場合は繁殖しない。子は親と同じ拠点を持つ。繁殖した拠点を世界史に記録し、適した地形と生きた群れが残っている間は地図に巣を描く。

### 固定世界の討伐圏
討伐依頼は集落からマンハッタン距離48タイル以内の到達可能な魔物を対象にする。冒険者は空腹になった時点で携行食を使い、食料が尽きて空腹が続く時や、対象が討伐圏の外に出た時は追跡を打ち切る。辺境の地形調査は別に続ける。

ギルドのある集落では、ゴブリン以上の攻撃力を持つ魔物の通常討伐にも、余力のある冒険者が同行できる。同行者も携行食を受け取り、加勢して帰還した場合は討伐実績を得る。

### 協力物資回収【暫定】

ギルドと冒険者が2人以上いる集落は、倉庫から8〜32タイルにある落とし物を回収する依頼を出せる。受注時に同行者と通常の携行食2食が必要。二人は同じ資源の山から分担して現物を回収し、倉庫の空きと入庫条件に従って納品する。回収済みの数量と担当者を保存する。

集落の周囲8タイル以内にゴブリン以上の攻撃力を持つ魔物がいると、集落ごとに1日1回まで接近を記録する。所属国は直近3日間の接近を防衛方針の判断に用いる。

食料難の集落では、協力物資回収を4以上残っている食料に絞る。未受注のほかの回収依頼は取り下げる。新規募集と受注時に、集落に回収品を受け入れる余地があるかを確かめる。受注済みの回収隊は帰還まで進行する。

### 協力資源調査での魔石発見【暫定】

鋼鉄鍛造を研究済みで、倉庫の利用可能な魔石が5未満の集落は、周囲4タイルの山地を含めて調べられる石材地を調査対象として優先する。二人で現地調査し帰還すると、探索済み・到達可能・空き地である近隣山地に魔石の鉱脈を5単位分発見する。石材地ごとに1回。鉱脈の発見は歴史に記録し、採集者が調査報告を参照する。倉庫への搬入は鉱夫の採掘と運搬を経由する。

魔石探鉱は以前に通常調査を済ませた石材地や枯渇した石材地にも出せる。適地がない場合、ギルドは倉庫から6〜24タイルの探索済み山地を直接調査する。二人が現地に到着して帰還し、鉱脈の候補地が空いていれば採掘可能になる。魔石探鉱は依頼枠が残り一つでも出せる。通常の資源調査には従来の条件が適用される。

巣の攻略は二人で出発する。同行できる冒険者と二人分の食料が揃うまで依頼は募集中になり、同行者が倒れたり撤退したりした場合は隊長も帰還する。過去セーブですでに単独出発していた依頼は続行できる。集落から8タイル以内にゴブリン級以上の魔物がいる場合、依頼の空きが一つなら討伐を優先する。

友好国の交易路でゴブリン級以上の魔物が経路の5タイル以内におり、どちらかの首都にギルド・成人冒険者二人・依頼枠があると護衛を募る。対象は倉庫間が96歩以内の交易。期日は経路長に応じて延長する。出荷後に新たな脅威が現れた場合も、引き渡し前に護衛を募集できる。二人が取引先の倉庫に到達して帰還すると積み荷を引き渡せる。期限切れや撤退、外交上の中断では荷は返送する。往路で危険な魔物と隣接すると交戦し、近くにいる二人が攻撃に参加する。負傷が深ければ撤退して交易品は返送される。討伐時の報酬は戦闘経験。

集落への脅威に対して依頼枠が埋まっている場合、未受注の調査だけを取り下げて討伐を募集できる。対象を失った未受注討伐は期限を待たず失効し、次の日次更新から通常の募集に戻る。

ギルド・食料2単位以上・成人冒険者二人を確保した集落は巣攻略を募集できる。対象が巣を作った未受注の通常討伐は、同じ巣に別の依頼がない場合に昇格する。空き枠がなく緊急の集落防衛もない場合は、到達できる巣の攻略で未受注の通常討伐を入れ替える。受注済みの依頼や、調査・護衛・物資回収はこの入れ替えの対象外。

交易護衛の近接戦では、隊員が持つ装備の近接攻撃・防御補正を適用する。護衛中の詠唱は対象外。

### ギルドでの後進育成【暫定】

ギルド近くで待機中の成人冒険者は、同じ集落で5回以上の依頼成功と戦闘Lv.2以上を持つ先輩から指導を受けられる。ギルドに到達可能で、戦闘・遠征の割当や生活上の危機がないとき、1集落につき1日1人へ経験4を付与する。指導者のレベルを上限とし、指導だけで戦闘Lv.4を超えない。昇級時に指導者と生徒を歴史に残す。

指導の機会は毎ゲーム時に確認する。戦争の行軍・包囲に参加中の住民は対象外。実施日は集落に保存し、同じ日に再開しても1日1回の上限を適用する。
