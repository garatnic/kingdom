# 11 画面・UI・演出
## 描画【確定】
細かい2Dドット絵。プログラム生成素材。作業と戦闘を細かく描写。HTML5 Canvasを中心に描画する案【技術選択は暫定】。
## 画面
上部：世界年・人口・国家・速度。中央：地形と人物。右側：選択した住民/建物/国家の詳細。下部：歴史イベントと操作。スマホは情報パネルを折りたたむ。
## カメラ【確定】
自由移動、ズーム、自動イベント追跡。人物・国家追跡も候補。手動操作時は自動追跡を一時停止。
## 表示密度
将来は数百人が賑やかに動くことを目標。ズームアウトでは個人描画を省略し、都市・領土を強調。
## アニメーション
歩行4方向、伐採、採掘、農業、建築段階、鍛冶、戦闘、詠唱、睡眠、会話。フレーム数・ピクセル寸法は暫定。
## 可読性
住民選択時に名前、種族、年齢、職業、現在行動、欲求、家族、所属国家、履歴を表示。イベント通知から現場へジャンプ。
