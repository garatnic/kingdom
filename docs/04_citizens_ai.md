# 04 住民・種族・家族・AI仕様書 — 詳細版 v0.2
> **確定方針**：多種族共存、個人の自律行動、出生・老化・死亡・家系記録、近景詳細/遠景簡略。以下の数値は**暫定**。

## 1. Ver.0.1範囲
初期12人、最大詳細100人程度。人間・エルフ・ドワーフ。職業：農民、木こり、鉱夫、建築家、冒険者。初期全員成人とし、開始直後の乳幼児扶養負担は回避する。国家は当初未成立、全員は同じ集落所属（初期から国家所属を必須としない）。二国目は後続の集落分離・建国で発生可能とする【暫定】。

## 2. 人物データスキーマ
```js
{
 id:"citizen:1", name:"アルディン", race:"human",
 birthWorldTimeTick:-8640000, alive:true,
 sex:"unspecified", // 出生モデルで必要な属性は後続定義
 settlementId:"settlement:1", nationId:null,
 homeBuildingId:null, familyId:"family:1",
 parentIds:[], childIds:[], partnerId:null,
 x:12.5,y:8.5, hp:100, hunger:20, fatigue:10,
 traits:{diligence:0.8, bravery:0.4, curiosity:0.6},
 skills:{farming:0,woodcutting:0,mining:0,building:0,combat:0,magic:0},
 profession:"woodcutter", inventory:{food:0,wood:0},
 action:{kind:"idle",phase:"plan",targetId:null,startedAt:0,progress:0},
 decisionAt:0, failedTargets:{}, lastKnownSafeTile:{x:12,y:8}
}
```
`ageYears` は保存時の正規値にせず、`birthWorldTimeTick` と `worldTimeTick` の差を432,000 tick/年で除して導出。出生前の初期成人は負の誕生時刻を許す。参照先はすべてID。死亡後は人物レコードを墓標/履歴として維持し、描画対象から除外。

## 3. 欲求モデル【暫定】
`hunger`, `fatigue`, `fear` は0〜100（大きいほど悪い）。`hp` は0〜100。空腹はゲーム内1時間で+3、疲労は活動中+2/時間、睡眠中-12/時間。食事1回で空腹-40、食料1単位消費。HP0で死亡。
- 空腹80以上で食事優先、100に達するとゲーム内1時間につきHP-3。
- 疲労85以上で睡眠優先、100で行動効率半減。
- 近接敵/襲撃危険が閾値超過なら逃走/戦闘を最優先。
- 空腹と食料消費量は経済仕様05と同じ値を参照すること（設定値の単一ソース）。

## 4. 意思決定【暫定】
候補行動 `eat, sleep, flee, fight, work, haul, socialize, explore, idle`。スコア `score = baseNeed + settlementDemand*traitMultiplier - travelCost - riskPenalty + continuityBonus`。候補ごとの基本値はデータ定義に置く。
- 即時割込み：死亡、敵接近、重大な空腹、対象消滅。
- 通常再評価：ゲーム内30分ごと、個体IDハッシュで分散。
- 継続ボーナス：現在行動に+15、最低継続時間はゲーム内15分（危険時は無視）。
- 同点時は安定した行動ID順で選び、ランダムなふらつきを防ぐ。
- 職業は国家/集落の不足需要に応じてゲーム内1日ごとに再割当候補を検討。住民の技能・性格を反映。

## 5. 行動状態機械
`idle -> plan -> travel -> perform -> carry -> deliver -> recover -> idle`。
- `plan`: ターゲット選択、必要資材・在庫・経路の予約。
- `travel`: 経路に沿い移動、障害物発生時に再探索。
- `perform`: 伐採/採掘/収穫/建築/戦闘を進行。作業進捗はシミュレーション時間で計算。
- `carry`: 実物の資源をインベントリへ保持。持てる重量を超えない。
- `deliver`: 倉庫・建築現場へ受渡し。成功したときのみ在庫移動を確定。
- `recover`: 休憩、食事、睡眠。終了後再評価。
- 対象が消滅/満杯/危険なら予約解除し、保持中の資源を失わず別の搬入先を探す。代替先がなければ安全な地面に落とし物を生成する。

## 6. 作業アニメーション
移動・道具を振る・木が揺れる・木が倒れる・荷物を持つ・倉庫へ置く。アニメーションは状態の表示であり、資源増減はシミュレーションの完了イベントで1回だけ確定。画面外でも同じ論理処理。

## 7. 家族・寿命【暫定】
- 1年=30ゲーム日（仕様03）。初期人間の成人年齢16歳、寿命目安35歳。エルフ/ドワーフは長寿傾向だが初版では人口バランスに合わせて係数調整。
- 婚姻候補はゲーム内1日ごとに照合。**出生抽選はパートナー単位でゲーム内1年に1回**（毎日抽選しない）。成人・相互関係・住居空き・食料備蓄・安全が前提。成立時に子ID、親ID、familyIdを原子的に追加し履歴イベントを生成。
- **初版は簡易的な家族形成**：関係値と同居の仕組みを持ち、妊娠・育児の詳細アニメーションは後続。年齢16歳未満は労働せず食料を消費し、成人で職業割当。
- 死亡時は全行動・予約を解除、所持品を地面へ移し、死亡イベントを記録。親子参照は消さない。
- 異種族間の婚姻/出生、寿命分布、出生確率は未決定。Ver.0.1は同種族の家族形成のみ【暫定】。

## 8. 不変条件
1. 全生存人物は存在する集落に所属。国家未成立ならnationId=null。
2. 全人物IDは生涯不変で再利用しない。
3. 親子関係は双方向一致、自己親子・循環を禁止。
4. 死亡人物は行動せず、家系・歴史から参照可能。
5. 1人物が同時に複数作業を進めない。
6. インベントリ資源は在庫と二重計上しない。

## 9. 受入テスト
T04-01：木こりが対象を選択→移動→伐採→運搬→納品。
T04-02：食料不足で仕事を中断して食事/調達へ切替。
T04-03：対象消滅時に予約解除、3回失敗後は別目標へ。
T04-04：出生後に親子参照が相互一致。
T04-05：死亡後も人物伝・家系図に残り、描画/AIから外れる。
T04-06：同一人物が二つの採集ノードを同時に消費しない。

## 10. 家族形成と出生の詳細【v0.3追加・すべて暫定】
- 成人年齢16年。生存成人は同一集落で相互に関係値60以上、互いにpartnerId=null、同種族、年齢差20年以内でパートナー候補。毎ゲーム日1回、ID順にペアを照合。重複マッチ禁止。成立時に両者のpartnerIdを原子的に更新し婚姻イベント。
- 子を迎える判定は同一集落に居住するパートナー単位で30ゲーム日（1年）に1回。住宅の空床1以上、食料備蓄が生存人口×3以上、敵襲なし、両者生存、家族の子が直近2年に出生していない場合、確率0.35/年。判定には保存済みPRNGを使う。
- 出生時は子のraceを両親と同種族、familyIdを共有、parentIdsを2つ設定。親のchildIdsにも追加。出生した子は0歳、職業なし、労働不可、食料消費あり。成人到達時に職業候補へ追加。
- 1年30日の時間圧縮では、出生率0.35/年でも通常速度で平均数時間に1出生。初版の30分テストに出生を必須とせず、倍速・シード指定テストで検証。
- 人間の自然寿命は30〜45年、ドワーフ40〜60年、エルフ50〜80年を暫定範囲とし、誕生時に寿命閾値を抽選して保存。自然死は年齢到達時。戦闘死・飢餓死は別判定。
- 初期住民の年齢は16〜28年から生成。出生前の初期成人は負のbirthWorldTimeTickを用いる。例示スキーマの20歳は整合する。
- 人口制御：出生成立条件は集落の食料備蓄が人口×3以上。人口×1未満は非常事態として当然出生停止（追加の別条件ではない）。住宅不足でも停止。人口上限100は描画・処理の目標であり、出生を突然禁止するハード上限ではない（性能上限は別途決定）。
- 異種族婚姻・出生の詳細は未決定で、初版は同種族のみ。多種族共存の確定方針は維持。

## v0.6 追加整合ルール【暫定】
- `birthWorldTimeTick` が唯一の出生時刻。`ageYears=floor((worldTimeTick-birthWorldTimeTick)/432000)`。
- 年次出生抽選は各パートナーの `nextBirthCheckTick` によって管理。初回は婚姻後1年、以後432000tickごと。セーブ/ロードしても抽選回数が変わらない。
- 婚姻条件の関係値60以上は双方の関係記録で評価。初期住民に関係値を生成しなければ婚姻が永久に起こらないため、初期関係値または交流による上昇を必須とする。
- 魔法適性は `skills.magic` と区別して `traits.magicAffinity`（0〜1）を保持。初期集落に適性者1名以上を保証する生成補正は暫定。研究08の `magicSkill>=1` は、適性者が魔法研究完了時に初級技能を獲得するルールで満たす。

## 追加種族【暫定】

生命創造でオーク（35〜55年）、ハーフリング（45〜65年）、妖精（60〜95年）を選べる。妖精の魔力適性は生成・出生とも0.75以上。初期住民は従来の3種族。探索後は、第30日以降15日ごとに最大1人、オーク・ハーフリング・妖精の順で移住候補となる。最新の探索地点と倉庫が通行可能な経路でつながり、空床と、移住者込みの人口×3以上の食料がある場合に、倉庫で受け入れる。生存人口300人以上では募集しない。
